# Mastering Database - FIAP

Repositório com exercícios da disciplina de banco de dados do curso de Análise e Desenvolvimento de Sistemas da FIAP, praticando conceitos fundamentais de SQL/PL-SQL de forma progressiva.

## Descrição

Este repositório reúne exercícios práticos organizados por tópico, cobrindo desde os conceitos introdutórios de banco de dados até estruturas mais avançadas como loops e manipulação de coleções (vetores).

## Estrutura do Repositório

```
fiap-2tdspo-sem1-mastering-database/
├── introduction-exercises/
├── conditional-exercises/
├── loops-exercises/
└── vectors-exercises/
```

| Pasta | Conteúdo |
|---|---|
| `introduction-exercises` | Exercícios introdutórios de banco de dados: sintaxe básica, consultas simples e primeiros contatos com SQL/PL-SQL |
| `conditional-exercises` | Exercícios utilizando estruturas condicionais (`IF`, `CASE`, `WHEN`) |
| `loops-exercises` | Exercícios utilizando estruturas de repetição (`LOOP`, `WHILE`, `FOR`) |
| `vectors-exercises` | Exercícios de manipulação de vetores/coleções (arrays, tabelas associativas) |

## Tecnologias

- SQL
- PL/SQL
- Banco de Dados Oracle

## Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/diandrade/fiap-2tdspo-sem1-mastering-database.git
```

2. Acesse a pasta do exercício desejado.
3. Execute os scripts em um cliente Oracle (SQL Developer, DBeaver, ou similar).

## Sobre

Repositório desenvolvido como parte das atividades semanais da disciplina de banco de dados no curso de Análise e Desenvolvimento de Sistemas da FIAP.
